# 大人の本格風水羅盤ナビ 🧭
### 3D立体工芸羅盤 ✕ リアルタイム電子コンパス ✕ 間取り気流シミュレーター

スマートフォンをかざすだけで、実物大の「高級電木 三元三合綜合羅盤」が回転し、方位測定・八宅風水鑑定・坐向判定・百二十分金（旺相・空亡）・気の流れシミュレーションが行える本格風水Webアプリケーションです。

---

## 🌟 主な機能と特徴

1. **実物大・高級電木綜合羅盤（3D/2D）**
   - 台湾・中国の高級電木羅盤（ベークライト）の工芸的質感を再現。
   - **正針百二十分金（120分金環）**：二十四山を各5等分した120区画を完全刻印。丙・庚・丁・辛の「旺相（大吉線）」を金文字で強調。
   - **八煞黄泉（黄泉八煞環）**：風水の最重要禁忌方位を可視化。
   - **天池（中心磁針室）**：南北海底紅線、北極双紅点（海底両点）、魚尾指南針、瑪瑙ピボット軸受。
   - **オイル減衰振動シミュレーション**：本物の液体封入羅盤の針の微小な揺れと収束挙動を再現。

2. **リアルタイム電子コンパス ＆ 坐向判定**
   - スマホの地磁気・ジャイロセンサー連動。
   - 現在向いている方位から「坐向（例：坐子向午・背北朝南）」を自動算出。
   - 現在の分金の吉凶（旺相・空亡・孤虚）をリアルタイム判定。

3. **水平気泡水準器連動**
   - スマホの水平状態（傾き）を検知。水平状態（±2度以内）になると緑のインジケーターが点灯。

4. **全画面羅盤（実機没入）モード**
   - スマホ画面全体を本物の羅盤として表示。

5. **3D立体工芸羅盤 ＆ 間取り気流実験室**
   - Three.js (WebGL) による3D立体鑑賞と、部屋の間取りに対する気の流れ（生気・煞気）シミュレーション。
